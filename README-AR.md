# Ouma — نسخة واجهة تجريبية

## محتويات المشروع
- `app/page.tsx`: الصفحة الرئيسية، الأقسام، البحث، المنتجات، السلة ونموذج بيانات التوصيل.
- `app/globals.css`: التصميم المتجاوب.
- `app/layout.tsx`: إعداد الصفحة والعنوان.
- `package.json`: حزم Next.js وReact.

## التشغيل
```bash
npm install
npm run dev
```

## ملاحظات مهمة
هذه نسخة واجهة أمامية تجريبية فقط. المنتجات والأسعار والمتاجر ورسوم التوصيل بيانات افتراضية.
نموذج الطلب لا يرسل طلبًا إلى متجر ولا يجمع مدفوعات. قبل الإطلاق الحقيقي يجب إضافة قاعدة بيانات، ولوحة إدارة، ونظام مصادقة، وربط مزودي الدفع والتوصيل، وسياسة خصوصية وشروط استخدام.
